# Camada de IA do atlas

Uma receita de harness caseiro para agentes de código (Claude Code, Codex, Devin, Copilot), sem instalação:
regras, perfil de comunicação e skills. É uma cópia gerada, um commit só: não edite aqui, porque a próxima
publicação troca tudo. Para usar, copie à mão os arquivos que quiser, na estrutura que preferir.

- `AGENTS.md`, `CLAUDE.md` e `PERFIL.md`: a entrada.
- `regras/`: o detalhe de cada regra.
- `perfil/jeito-de-falar/` e `.claude/`: as skills, os agentes e a regra de código.

Os comandos usam marcadores entre `<>` (`<issues>`, `<dono>`, `<raiz>`), que se preenchem num arquivo
fora do git. Algumas regras citam skills, testes e ganchos que não vêm nesta cópia: onde faltarem,
vale a regra sem eles.
